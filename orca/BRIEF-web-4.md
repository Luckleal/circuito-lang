# Brief 4: written analysis ("Análise") and the why of every result

Scope for the Codex worker: new `web/js/analysis.js`, new `web/css/analysis.css` (one `<link>` line in index.html), the tab wiring in `web/index.html`/`web/js/main.js`, and the i18n dictionaries (all 7 languages, same keys). Do NOT edit `web/js/circuit.js`, `player.js`, `gates.js`, `table.js`, `web/css/circuit.css` (another agent owns them). No browser tool; check with `node --check` and curl against http://127.0.0.1:8765/.

Add a result tab **"Análise"** (first position after Diagnostics or replacing nothing: keep all existing tabs). It is a readable written report, generated only from real API data (`/api/analyze` -> `summary`, `stages`, `diagnostics`, `ast`, `circuit`, `delays`; `/api/simulate` -> `why`, `steps`, `bits`). No invented facts. Sections, each a short paragraph/list in the active language:

1. **Resumo**: one sentence verdict (valid circuit / which stage failed) + the circuit name.
2. **O que cada etapa fez**: lexical (n tokens, kinds), syntactic (n CST nodes -> n AST nodes, why the AST is smaller: punctuation and grouping removed), semantic (rules checked: declarations, drivers, buses, loops; warnings), circuit (n gates by kind, logic depth, inputs/outputs/wires). Blocked stages are listed with the reason ("bloqueada porque a etapa X falhou").
3. **Se houve erro**: for each diagnostic, a plain-language explanation of WHY it is an error and how to fix it, keyed by the message pattern (undeclared signal, used before declaration, duplicate declaration, assignment to input, multiple drivers, bus index out of range, bus without index, index on scalar, invalid constant, output/wire never driven, combinational loop, zero-width bus, plus lexical/syntax errors in general). Show the original compiler message (English) and the excerpt of the source with the offending range marked; a "ir para o código" button.
4. **Equações**: the circuit as readable equations (`summary.equations`) plus the precedence note (NOT > AND/NAND > OR/NOR/XOR/XNOR, left associative) when parentheses were added by the compiler.
5. **Por que o resultado? (entradas atuais)**: for each output, a derivation sentence tree built from `why`: "sum = 1 porque XOR(p=1, Cin=0) = 1 (XOR vale 1 quando as entradas são diferentes); p = XOR(A=1, B=0) = 1 ...". Per-operator one-line rule text (AND, OR, NOT, XOR, NAND, NOR, XNOR, buffer, constant). Updates when inputs change (re-fetch `/api/simulate`). A compact "when is this output 1?" line from the truth table summary if the table was generated.
6. **Atrasos** (only if `summary.uses_delays`): critical path chain and total ns, with the sentence that delay is the sum of `@delay` along the slowest path (static, no glitches).
7. **Limites desta análise**: truth table is a conference aid, animation is didactic not temporal.

Quality bar: same as brief 2/3 (no generic AI look, strong typographic hierarchy, mono for code/values, 1px rules, subtle accent). Print-friendly. Add "Copiar análise" (plain text) and "Baixar .md" buttons. Stale results banner applies. Report briefly.

Scope for the Antigravity worker (mobile): see `orca/BRIEF-web-3.md` plus: on 390x844 and 820x1180 the Circuit and Truth-table tabs must be compact and fully usable (icon-only toolbar in one row, player compacted with a collapsible scrubber, inspector as a bottom sheet, hint hidden until selection, circuit fitted on open, no horizontal page scroll). Also add, inside the gate inspector, a "Por quê" line: the operator rule text for the current values ("AND = 1 só quando todas as entradas são 1").
