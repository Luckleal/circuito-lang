# Brief 6: static hosting polish (loading state, shareable link, text size)

The site now also runs without a server: `web/js/backend.js` detects the local server (http) or runs the real Python compiler in the browser through Pyodide (`web/js/pyworker.js`). The first load downloads the runtime (~10 s on slow links). Do not change `backend.js`/`pyworker.js`/`api.js` behaviour except to read the `backend:status` events they dispatch on `window` (`detail: {engine:'wasm', state:'loading'|'ready'|'error', step:'runtime'|'compiler'}`).

Write scope: `web/index.html`, `web/js/main.js`, `web/js/quick.js`, new `web/js/share.js`, new `web/js/status.js`, new `web/css/extras.css` (one `<link>`), `web/styles.css` (only if needed), all 7 i18n dictionaries (same keys everywhere). Do NOT touch circuit/player/gates/table/analysis files. No browser tool; `node --check` (copy to .mjs for ESM) and curl http://127.0.0.1:8765/. No commits.

1. **Loading state.** While the in-browser compiler loads show a slim, calm status line (top of results pane, not a modal) "Preparando o compilador… só na primeira vez" with the step, an indeterminate progress bar (transform-only animation, static under reduced motion), and on error a short message + "Tentar novamente" button. Work typed while loading must NOT be lost or reset: the quick input keeps its text, analysis runs as soon as the compiler is ready. Nothing is shown in http mode (instant).
2. **Shareable link.** A discreet "Copiar link" icon button in the header. In quick mode it copies `<page url>#e=<encoded expression>`, in full mode `#c=<base64url of the UTF-8 code>` (refuse above ~6000 chars with a short message). Opening a link with `#e=` or `#c=` selects that mode, loads the text and analyzes automatically; the hash takes precedence over saved state. Feedback: the button label briefly becomes "Link copiado" (aria-live), fallback to a prompt-free selectable field if the clipboard API is unavailable. Use `URL`/`history.replaceState`, no libraries.
3. **Text size.** One compact control (A− / A+, 3 steps: 100%, 125%, 150%) persisted in localStorage (try/catch), scaling code, the quick input, tables and the explanation text through a CSS variable; layout must not break at 150% on 1440x900 or 390x844.
4. Keep the UI uncluttered: no new panels, no instructional text blocks, no mentions of classrooms/teachers. All new strings in 7 languages. Same visual quality bar as before. Report briefly.
